# 5 Frontend Mini Projects

Five small, self-contained frontend projects — each built with plain **HTML, CSS, and JavaScript** (no frameworks, no build tools). Every project runs by simply opening `index.html` in a browser, and each has its own `README.md` with a screenshot.

| # | Project | Folder |
|---|---------|--------|
| 1 | Digital Clock & Stopwatch | `01-digital-clock-stopwatch/` |
| 2 | Number Guessing Game | `02-number-guessing-game/` |
| 3 | Daily Expense Tracker | `03-expense-tracker/` |
| 4 | QR Code Generator | `04-qr-code-generator/` |
| 5 | Random Password Generator | `05-password-generator/` |

## How to run any of them

No installation, no npm, no server required:

1. Open the project's folder.
2. Double-click `index.html` (or right-click → Open with → your browser).

Every project's own `README.md` has more detail, feature list, and a screenshot.

## What's inside each folder

```
0X-project-name/
├── index.html
├── style.css
├── script.js
├── README.md
└── screenshots/
```

(The QR Code Generator has one extra file, `qrcode-lib.js` — a small self-contained QR encoder, since it needed to work fully offline.)
